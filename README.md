# NFSMW Actions — teste de infraestrutura

Repositório de teste para medir recursos do GitHub Actions e desempenho de compilação **sintética** C++ com CMake/Ninja.

**Este repositório não contém o Need for Speed: Most Wanted, código recompilado do jogo, APK, ISO, chave de assinatura ou credenciais.**

## Como executar

Na aba **Actions**, selecione **NFSMW - diagnostico de compilacao C++ (sem jogo)**, depois **Run workflow**. Após a execução, abra o job para consultar o log e o resumo com CPUs, memória, disco e duração do benchmark.

A medição é apenas um diagnóstico preliminar de infraestrutura; **não mede o tempo de compilação real do NFSMW**.
